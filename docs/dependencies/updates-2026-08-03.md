xterm beta channel, refreshed both Rust lockfiles, and moved the MCP backend to
Sentry 0.49. The daemon now uses the workspace's existing `base64` 0.23 release

while the latest `tauri-plugin-sentry` requires that client version.

## Source migrations

Sentry Rust 0.49 makes `ClientOptions` non-exhaustive and replaces direct
`traces_sample_rate` field construction with a sampling strategy. MCP
observability now uses the documented `ClientOptions` builder methods,
including `.traces_sample_rate(...)`, while preserving the previous release,
environment, stacktrace, PII, log, and trace-sampling settings.

No other source or configuration migration was required. No core JavaScript
major release changed.

## Deferred updates and exact blockers

- Tauri `sentry` 0.42 -> 0.49 is deferred. The latest
  `tauri-plugin-sentry` 0.5.0 depends on Sentry 0.42 and accepts that version's
  `sentry::Client` type. Updating the direct Tauri dependency alone would add a
  second, incompatible Sentry client stack. MCP was independently upgraded to
  Sentry 0.49 successfully.
- The 44 remaining JavaScript advisories are transitive and remain deferred
  pending compatible fixed upstream dependency graphs.
