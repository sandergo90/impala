# Dependency updates — 2026-07-27

## Summary

Updated all JavaScript direct dependencies reported by the registry, while
preserving the repository's xterm beta channel, and refreshed both Rust
lockfiles. The MCP backend moved to the current `base64` and Sentry release
lines; the Tauri backend moved to `base64` 0.23 and `window-vibrancy` 0.8.
Typechecking, the production frontend build, both Rust checks, and all Rust
tests pass.

`tauri-plugin-sentry` can consume a newer Sentry client type.

## Deferred updates and exact blockers

- Tauri `sentry` 0.42 → 0.48.5 is deferred. `tauri-plugin-sentry` 0.5.0
  accepts a `sentry::Client` from its pinned Sentry 0.42 dependency. A direct
  Sentry 0.48 client is a different Rust type, producing `E0308` at
  `tauri_plugin_sentry::init`. Restoring only Tauri's direct Sentry requirement
  to 0.42 removes the duplicate incompatible graph and returns the workspace to
  green. MCP remains successfully upgraded to Sentry 0.48.5.
- The 44 remaining JavaScript advisories are transitive and remain deferred
  pending upstream releases with compatible fixed dependency graphs.
